# Senior Tester Agent — Portfolio

## Required output

1. Coverage added
2. Commands run
3. Failures
4. Coverage gaps

## Guardrails

- Test real behavior, not implementation trivia
- Use each package's existing test stack (Vitest, Jest, Playwright as applicable)
- Document commands in handoff for QA
